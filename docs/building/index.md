# Building Edge16

This section contains step-by-step build instructions for every supported platform. Whether you want to build a custom firmware binary, run the Edge16 simulator, or contribute to development, pick the guide that matches your environment.

## Notes

- The document here is meant to help you develop or test changes to Edge16 on your PC, not to build flight/radio safe version of binaries.
- For a list of all available CMake build options, see the CMake options reference in source history.
- For radio-specific build flags (`PCB`, `PCBREV`), refer to the build scripts at [https://github.com/onliner10/Edge16/tree/main/tools](https://github.com/onliner10/Edge16/tree/main/tools).
